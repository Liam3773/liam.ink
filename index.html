What changed

Less placeholder. More presence.

The homepage now acts like a proper club front door instead of a basic static page: stronger branding, calmer section spacing, lighter cognitive load, and a smoother, more confident first impression.

Hero as a real image Uses hero.jpg as the visual centrepiece instead of reusing the photo grid.
Gallery with depth Editorial mosaic layout, keyboard-friendly lightbox enhancement, and lazy-loaded images.
Reviews with polish Accessible labels, upload preview, progress, cooldown countdown, and live Firestore updates.

Club identity

A public homepage and a separate admin path should feel like two different tools.

The public page should sell the club story in seconds, then make it effortless to browse photos or leave a message. Moderation belongs in /admin/, not in the root user journey.

01

Sharper visual hierarchy

Stronger heading scale, calmer section spacing, and clearer call-to-action placement make the page easier to scan, especially on mobile and first load.

02

Gallery that feels intentional

The four bottom images now sit in an asymmetric layout with full-size viewing support, which gives the page more personality without adding new assets or heavy scripts.

03

Reviews with better trust signals

Character counting, progress states, file preview, success/error messaging, and the five-second cooldown all reduce confusion and accidental repeat submits.
